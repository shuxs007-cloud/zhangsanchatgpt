# OpenSMS 代码导出

430/：主项目源码、脚本、测试、规则和项目资源。
shared/：共用入口、绑定工具和 CloakBrowser 项目。

仅导出代码，不含聊天记录、技能包、业务数据库、历史报表、浏览器配置、登录凭据、运行锁及 node_modules。部分测试表格与业务输入数据也不包含。排除项见 EXCLUDED.json。源码保持原样，可能包含内部地址或标识，请按私有代码保管。

新电脑需要安装 Node/Python 及依赖，调整原用户名绝对路径，并重新登录。不得直接复用旧锁、会话或重放提交。此包不等于可直接恢复全部业务状态的迁移包。

没有自动安装、自动启动或自动执行任何业务。
