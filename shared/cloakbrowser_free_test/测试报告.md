# CloakBrowser 免费版只读测试

执行日期：北京时间 2026-10-01。未启用付费许可，未充值。

| 测试项 | 结果 |
|---|---|
| 已安装包装器 | cloakbrowser 0.5.11 |
| 实际免费浏览器 | macOS ARM64 Chromium 145.0.7632.109 |
| 下载完整性 | 官方 Ed25519 签名、SHA-256 校验通过 |
| 网站首页和 /day | 两次页面请求均 HTTP 200，重定向到登录页 |

| 绑定新增/删除 | 0 / 0 |
| 430 对照只读查询 | 首次 HTTP 403；冷却30秒、刷新后，运营商查询成功 |
| 凭据处理 | 未复制430 Cookie、未提交用户名或密码 |
| 执行协调 | 测试持有共享430会话锁；测试结束浏览器关闭、锁释放 |

## 结论

免费旧版可以打开网站，但没有证明能解决登录后接口403；页面200不等于人机验证通过。
430本轮在冷却刷新后也恢复成功，不能把恢复归因于换浏览器。当前不建议依据本次结果付费。

邮件里的固定指纹、复用登录配置有集成价值，但第三方Cookie、住宅代理、拟人化输入
不是本次测试的必要改动。未轮换IP、未自动完成验证码、未修改现有绑定流程。

官方说明：最新版也可通过GitHub登录领取单并发免费密钥；本次测试的是无需密钥旧版，
不能代表最新版或Pro效果。下一阶段需人工领取免费密钥并人工登录，再对相同只读接口比较。
