逐字段系统值优先。旧导出格式没有日期列时允许同轮系统库存作为旧格式来源；不是用库存非空值抢占新源表字段。系统截止日直接使用，不从系统激活日期重算。

## 并发和顺序

| 工作 | 调度方式 |
| --- | --- |
| A新鲜来源采集 | 新鲜导出、Google、系统库存、已上架号码、余量等五路不冲突工作并发 |
| 文档生成/复核 | 源表、Google、系统库存、冻结日期库四路读取；固定规则使用一次扫描缓存，文档校验有界并行 |
| F查询 | 初始文档独立复核后启动独立后台作业；请求8个隔离会话，实际不超过缺口数；会话内串行及每条至少1秒 |
| 只读分页/哈希 | 根据现有规则使用4或8个有界工作器；逐页校验完整性，独立回读不复用首遍哈希 |
| 普通/B/C/D/E写入 | 仍按写入→独立回读→刷新屏障逐阶段执行；不提前用旧文档生成下阶段候选 |
| F入库/增量 | F作业排他锁及跨作业写库锁；查询→完整回执→事务入库→增量/快照导出→独立核验顺序执行 |

主要提速来自F不再占用主报表交付等待时间。F作业有独立job清单、输入副本、状态、日志、报告及交付目录，不修改已发布主表/主清单。F失败单独报告，不将已核验主任务改判失败。不能据此承诺实际网络端到端固定两分钟。
