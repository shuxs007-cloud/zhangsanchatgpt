# Grab ICCID 查询工具：Mac 完整包

## 启动

1. 完整解压 ZIP。保留整个文件夹，不能只复制 Start.command。
2. 双击 `Start.command`，浏览器打开 `http://127.0.0.1:43883`。
3. 粘贴 ICCID 后点击“开始新查询”。未登录时会弹出独立 Chrome / Edge 窗口，请手工登录；成功后继续断点。

包内包含 Apple 芯片 arm64 与 Intel x64 两套官方 Node 运行时、程序源码和导出依赖。启动脚本自动选择架构，无需安装 Node、npm、Codex 或 Excel。电脑需要已安装 Google Chrome 或 Microsoft Edge，并能联网访问 Grab。浏览器不包含在包内。

这是命令脚本版，不是已签名公证的 App Store 应用。第一次打开如被 macOS 安全机制阻止，请先确认来源和 SHA256，使用系统提供的单次打开确认，或联系管理员。不要关闭 Gatekeeper、安全软件或删除系统安全策略。被组织策略禁止时不绕过。

## 日常操作

- `Start.command`：启动后台服务并打开网页。也支持终端执行 `./Start.command --no-open`，只启动服务。
- `Stop.command`：保存断点并关闭后台服务；当前只读请求最长约 60 秒收尾。关闭网页不等于关闭服务。
- `Check.command`：离线自检，使用临时模拟号码，验证状态、历史与 Excel。不会登录网站或读取正式历史。
- `OpenData.command`：用 Finder 打开本地数据目录。

页面中的“停止”结束当前查询任务；Stop.command 是暂停保存后退出程序。暂停/失败的任务可继续未完成项，停止的任务须新建才能重查。程序重启后不会自动开始业务查询。

## 查询与导出

大文本框可粘贴多条 ICCID，支持换行、空格、逗号、分号分隔。只去掉末尾一个 F/f，按处理后的 ICCID 去重，原始输入与重复次数仍保存。每个新任务全部实时查询，不读取历史结果充当新结果。

页面实时展示已查、剩余、结果及状态。完成后导出 Excel，含查询结果、汇总说明、原始清单；ICCID 完整保存为文本，不丢位。暂停/停止/失败后有结果时可导出明确标注的部分报告，未查项显示“未查询”。

历史列表保存开始/结束时间、条数、结果与下载。激活成功只依据明确 Activation Date；激活中表示有申请日期而激活日期为空；两个日期均空为未激活。不存在只表示当前账号完整 ICCID 查询返回零条，网络或登录错误不算不存在。

Grab 同一会话表单有状态，查询请求串行、间隔至少 1 秒，支持批量搜索后精确匹配。Excel 在独立进程生成，不阻塞页面响应。所有业务操作由本地程序执行，不调用 AI。

## 数据与旧版本

默认本地目录：`~/Library/Application Support/GrabQueryTool`

- jobs：历史与断点。
- reports：Excel 与查询快照。
- server.log：服务日志。
- login-browser：专用浏览器配置，可能包含持久登录状态；不要分享。

本包从空历史开始，不包含 Cookie、账号密码、历史查询和用户 ICCID 清单。Cookie 只提取到进程内存用于请求，不进入报表或查询记录；浏览器自己仍会保存登录状态。

为不影响旧 Mac 版，本包默认用 43883 端口、独立数据目录，不改动旧版 43881 服务和 Downloads/430 下的历史，也不自动连接旧版比特浏览器配置。不要让两个版本共用同一登录会话同时查询。

更新前先 Stop，再解压新版本。历史数据不在程序文件夹内，替换程序不会清除它。备份只复制 jobs 与 reports，避免分享 login-browser。

## 可选配置

一般无需配置。将 config.example.json 复制为 config.json 后可以设置端口、浏览器绝对路径、dataDir、reportsDir。留空使用默认值。自定义路径必须是绝对路径，不用 `~`。

`bitBrowserPortFile` 可指向你明确选择且已运行的比特浏览器配置的 DevToolsActivePort 文件；留空只使用独立登录浏览器。本包不扫描其他浏览器配置。

未修改 OpenSMS 任务、运营商、SIM 激活记录、下卡通知或到期标记。

## 验证及依赖

当前 Apple 芯片 Mac 上验证包内运行时、启动脚本、独立依赖、自检、浏览器 UI（模拟查询）、暂停/继续/停止、历史和 Excel 下载。Intel 运行时来自官方并校验 SHA256，但没有 Intel 实机。此次打包不执行真实 Grab 账号查询。

Node.js v24.21.0、Playwright Core 1.62.1、ExcelJS 4.4.0。使用可独立分发的开源导出库，不依赖 Codex 专用表格运行时。第三方许可证随包保留。

官方发行及校验：https://nodejs.org/dist/v24.21.0/
